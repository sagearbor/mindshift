# D — voice-separability dashboard

`compute.py` measures every fixture on 100 ms hops (Praat F0 + formants via parselmouth, librosa spectral centroid / tilt / RMS, energy-VAD silence skipped), embeds 1.5 s windows (hop 0.25 s) with the pinned ECAPA model (`speaker_id.embed_pcm_batch`, raw vectors cached in `emb_*.npy`), pools per-ground-truth-speaker voiceprints for the cosine matrix, and runs the production diarizer (`diarize_local.diarize_turns`) on the ground-truth intervals (plus the two stored Deepgram transcripts for maggiano3); `build_html.py` inlines the resulting `data_*.json` into the self-contained dashboard `tmp/voice-dashboard-20260829.html` (sticky fixture switcher, raw-feature overlay chart with toggles and the owner's rubric as optional bands, production strip, per-speaker distributions, embedding scatter + heatmap, ranked separability text); `summarize.py` prints the numbers below. Separability ratio = std of per-speaker medians ÷ mean within-speaker IQR/1.35; "alone" = frame accuracy of a nearest-median classifier on that single feature (chance = 1/k). **Best single feature per fixture:** maggiano3 (k=3) → Pitch 1.17 (64% alone), then centroid 0.76, tilt 0.65, F1 0.60; ECAPA labels 73% of windows by nearest pooled voiceprint (all pooled pairs ≤ 0.24 cosine), yet production with the rubric turns finds only 2/3 voices (52% frames, mom merged into dad) because k=3 fails the 1.5 s min-cluster-seconds gate (a 1.0 s cluster at separation 0.207), not a voice-similarity gate; the stored transcripts give 3/3 at 64% and 57%. poker6 (k=6) → Pitch 1.75 (40% alone, chance 17%; Player1/Player5 share a 111 Hz median so pitch alone cannot split them), then F2 0.85, F1 0.65, energy 0.50; ECAPA 83% by nearest voiceprint, closest pair Player2–Player6 0.30; production 6/6, 100%. family_real (k=2) → F1 0.90 (76%), energy 0.73, pitch 0.63, centroid 0.61; ECAPA 96%, pooled cosine 0.07; production 2/2, 100%. scene_family3 (k=3) → Pitch 1.52 (76%), F3 0.83, tilt 0.62; ECAPA 100%; production 3/3, 100%. scene_meeting4 (k=4) → Pitch 1.44 (64%), F3 0.65, tilt 0.61; ECAPA 97% of windows but Speaker B–D pool at 0.72 cosine (same TTS voice to the model) so production stops at 2/4, 60%. openai (k=2) → Pitch 3.08 (97%), F3 0.81, centroid 0.80; production 2/2. gptaudio (k=2) → Pitch 1.73 (87%), F3 0.65, centroid 0.63; production 2/2. scene_couple (k=2) → Pitch 2.36 (97%), F3 1.01, tilt 0.67; production 2/2.
